SamyataTM - Return Policy

Last modified January 21, 2019

By placing a Samyata order you acknowledge and understand that attempting to collect a cash refund for a credit card purchase or initiating a fraudulent chargeback is prohibited by law and you hereby agree to indemnify, defend and hold harmless Bodaty, the merchant and each of their affiliates from any claims, losses or liabilities arising from or in connection with your violation of the applicable return policy.

Samyata Return policy is based on the merchant's return policy. Return window will be mentioned clearly in the product details page.

In general, an item may be eligible for return within the applicable return window if it fulfills one or more of the following conditions:

  • Was delivered in a physically damaged condition
  • Has missing parts or accessories
  • Is different from what was ordered
  • Is different from its description on the product detail page on Samyata

1. Products marked as "non-returnable" on the product detail page cannot be returned.

2. All items must be returned in their original condition, with price tags intact, user manual, warranty cards, original accessories and in the original manufacturer’s box/packaging as delivered to you. Refer to instructions to return items against each category. We may reject the return pickup if the items are not returned according to the policy mentioned against each category.

3. If you wish to return an electronic device that stores any personal information, please ensure that you have removed all such personal information from the device prior to returning. Samyata will not be liable in any manner for any misuse or usage of such information."

4. In some cases, at the merchant’s discretion, items may not be eligible for return, including cases of buyer's remorse such as incorrect model or color of product ordered or incorrect product ordered.

5. All returns are subjected to Sellers approval of return.

Clothing and Accessories

Clothing and Accessories/Clothing, Jewellery, Watches, Eyewear, Hand Bags, and Luggage Bags, Shoes and Baby Products. Return based on merchant return policy
Any product under Clothing and Accessories is nonreturnable if it said non-returnable on the product details page.
Returns are accepted by the merchants only if the clothing and Accessories are in the original condition with the MRP and brand tag attached to them.
Returns are accepted only within return window of the merchant.

Furniture

Furniture/Bedroom Furniture, Dining and Kitchen Furniture Office Furniture and Living Room Furniture Return based on merchant return policy.
Any product under furniture is nonreturnable if it said non-returnable on the product details page and Returns are accepted by the Merchant if the product is damaged before you receive it.

Books

Books/General Books, Text Books, Religious Books,Magazines and subscriptions and Magazines Return based on merchant return policy.
Books that are labeled as non returnable on the product details page are not eligible for returns.

Electronics

Electronics/TV,Laptops,Mobiles, projectors and Audio Devices Return based on merchant return policy.
All the products under the electronics category are eligible for returns within the return window of the merchant and also should satisfy the conditions below:
Returns should be placed only if the laptop is in the original condition with the original brand box and all accessories like charger, manual, Items are accepted only in the return window of the store and eligible for return if the TV is in the original condition in brand box and all the accessories Product like TV remote etc. to avoid pickup cancellation.
Returns are accepted only if the mobile is not damaged while in your possession, or is not different from what was shipped to you.
Audio devices can be accepted only if they are returned under original conditions.

Home,Garage, and Office

Home, Garage, and Office/Car Accessories, Microwave Ovens and Ranges, Coffee Tea and Espresso, Mixers and Refrigerators, Steamers, Rice Cookers, Pressure Cookers, Dishwashers, Washing Machines, Vacuum cleaners, and candles. Return based on merchant return policy.
Items under this category are not eligible for return if it said non-returnable on the product details page.

Software

Software Return based on merchant return policy.
Software products that are labeled as non-returnable on the product detail pages are not eligible for returns.
For software-related technical issues or installation issues in items belonging to the Software category, please contact the brand directly.

Foods and Accessories

Foods and Accessories/Grocery Gourmet Food, Candy, Prepared Foods, Supplements, Bottled Water, Soft Drinks Most Of the items are nonreturnable and Returns are accepted for few products based on merchant return policy.
Products which are labeled as non-returnable on the product detail pages are not eligible for returns.

Beauty and Personal Care

Beauty and Personal Care/Beauty, Haircare Accessories and Non-Prescription Return based on merchant return policy.
You can return the product only in the merchant return window and it should also satisfy below conditions:
If you receive the product in a damaged state and also received a product different from product details page.

Smart Homes

Smart Homes/Smart Home, Security and Wifi Return based on merchant return policy.
You can return the product only in the merchant return window.

Entertainment

Entertainment/Movies, Toys and Collectables, Drones and Drones Accessories, Xbox One, PlayStation, Nintendo Switch and more gaming Return based on merchant return policy.
You can return the product only in the merchant return window

Sports and Fitness

Sports and Fitness Return based on merchant return policy.
You can return the product only in the merchant return window
Inner apparel, socks, gym supporters, guards are usually "non-returnable". Even if they are eligible for returns they are accepted only in the return window of the merchant.
Refunds will be issued only if it is determined that the item was damaged while in your possession, or is not different from what was shipped to you.
